# AimScope

Local-first browser aim training and sensitivity assessment prototype.
本地运行的鼠标灵敏度与瞄准跟踪测评工具。

## 功能

- 快速定位、微调瞄准、连续跟踪、大角度切换四种练习。
- CS2 与无畏契约默认腰射灵敏度换算；不读取游戏进程或改写游戏设置。
- 热身、五档初筛、三档精测、两次候选与原设置的对照；顺序随机且第二次对照反向。
- 横移跟踪报告包含贴合比例、角度误差、恢复耗时与未恢复次数。
- 最近 20 次测评保存在当前浏览器 localStorage，没有登录、遥测或聊天数据。

## 安装运行

需要 Node.js 24+、pnpm 及桌面鼠标。使用桌面 Chrome 或 Edge。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:3000 。填写硬件 DPI 和游戏内灵敏度，先快速体验，再做完整测评。开始时授权全屏并点击锁定鼠标；Esc 退出锁定，本轮暂停并在恢复时重来。完整测评约 16 分钟，另加休息。

```powershell
pnpm test
pnpm build
pnpm preview
```

preview 的网址以终端输出为准。构建产物在 dist，可作为静态网站部署；仓库提供源码，未部署公共演示站点。

## 数据与限制

运行时没有应用 API、云端推理或自动上传。安装依赖需要访问包仓库。浏览器清除网站数据会删除测评历史；不同端口/浏览器历史不共用。此版本使用独立历史键，不读取旧工具记录。

结果是启发式建议，不是科学验证的最佳灵敏度、段位评估或硬件延迟测量。eDPI 不能跨游戏直接比较；默认腰射常数不覆盖 ADS、自定义 yaw、驱动加速等。熟悉度、帧率和视野会影响成绩。建议跨日复测并在实际游戏验证。

## 算法

四项等权。跟踪评分由 80% 贴合比例和 20% 速度变化后恢复表现组成。连续贴合 80ms 才算恢复，未恢复计零。候选两次对照均领先超过 3 分、平均超过 5 分且满足输入和完整性条件时才建议调整。精测边界最优不视为全局最优。

## 项目范围

这是从本地原型抽取的独立版本，不含 CS2 压枪场景、游戏模型、纹理、动画、音效、微信数据、模型权重或任何密钥。不是 Valve、Riot Games 或其他瞄准训练产品的官方项目。
